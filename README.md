# Examen Teórico · Categoría B

Simulador multiple choice del examen teórico para la licencia de conducir Categoría B (autos, B1 y B2), basado en el manual de preguntas del Municipio de Lanús.

- 95 preguntas: 30 generales, 16 específicas de autos y 49 de señales de tránsito.
- Corrección inmediata (verdadero / falso) con la respuesta correcta.
- Estadísticas finales; se aprueba con el 75%.
- Preguntas de alcoholemia actualizadas a Alcohol Cero (Ley 27.714).

Es un único `index.html` estático, sin dependencias.
